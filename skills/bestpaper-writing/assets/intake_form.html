论文信息表

填写你的工作信息，导出 JSON 后交给 Best-Paper-Writing-Skill 生成论文底稿。可以用中文写，也可以直接粘贴幻灯片文字、实验表格和组会笔记。必填 5 项填完就能导出；⭐ 推荐项决定底稿有没有获奖论文的“韵味”，没填的 skill 会先追问一次；其余都是补充。内容自动保存在本浏览器中。

💡补充的内容越详细，底稿质量越高。每多填一项，稿子里就少一个 [TODO]；机制、公式和数字没有给出时，skill 只会标 [TODO]，不会自行编造。

缺项检查

导出的文件可用 python3 scripts/intake_to_brief.py 文件.json 转成写作简报，或直接把 JSON 交给 agent：“用 Best-Paper-Writing-Skill，根据这份信息表 JSON 写出论文的 Title、Abstract、Introduction、Methods 和 Experiments。”
